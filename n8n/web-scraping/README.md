# Web Scraping Automations

Automations for extracting structured data from websites.

## Current automation

### Product Data Extractor

Extracts structured product information from e-commerce websites, including:

- Product title
- Description
- Price
- Product URL
- Image URL

The workflow can then prepare the extracted product content for embeddings and storage in a Supabase vector store.

## File naming

Use descriptive lowercase names with hyphens, for example:

`product-data-extractor.json`
