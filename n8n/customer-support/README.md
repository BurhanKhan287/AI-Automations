# Customer Support Automations

n8n workflows for automating customer support operations, including AI-assisted responses, knowledge retrieval, ticket handling, and support workflows.

## Workflows

Add exported n8n workflow JSON files to this directory.

### Naming convention

Use lowercase, descriptive names with hyphens:

`customer-support-<purpose>.json`

Examples:
- `customer-support-agent.json`
- `customer-support-rag.json`
- `customer-support-ticket-routing.json`

> Credentials and secrets are not stored in this repository. Reconnect credentials after importing a workflow into n8n.
